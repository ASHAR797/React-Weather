# 🌦️ React Weather Dashboard

A modern, dark-themed weather dashboard built with **React**, designed to display weather information through a clean, detailed, and responsive interface.

The project focuses on presenting real-time weather data in a visually engaging way, with a distinctive dark aesthetic and purple accents.

## 🎨 Design Preview

![Weather Dashboard](./src/assets/weatherdashboard-img.jfif)(https://react-weather-p887.vercel.app/)

## ✨ Features

- **City Search** — Search for weather information by city.
- **Current Weather** — View the current temperature and weather conditions.
- **Feels Like** — Check the perceived temperature.
- **Weather Metrics** — View humidity, pressure, and visibility.
- **Wind Information** — Check wind speed, direction, and gusts.
- **Sunrise & Sunset** — View daily sunrise and sunset times.
- **Location Details** — Display geographical coordinates and timezone.
- **Weather Map** — Visual location section with a map preview.
- **5-Day Forecast** — Preview upcoming weather conditions.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided in your terminal.
